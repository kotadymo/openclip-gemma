# v0.4.0 Development Progress

## Current phase

Implementation and local validation are complete on
`feature/v0.4.0-matryoshka`. Review, CI, and release gates remain pending;
changes are still uncommitted.

## Baseline and verified decisions

- Starting `main` commit and tag: `e5fce9b1af9455ce1e5d9d651143ea5b22275164`
  (`v0.3.0`); the worktree was clean.
- The v0.3.0 compatibility specifications and historical inference contract
  were read. Existing default embeddings, prompts, preprocessing, strict
  logit behavior, and 768-dimensional indexes are the compatibility baseline.
- Public PyPI reports version `0.3.0` with one wheel and one sdist;
  TestPyPI reports `0.3.0rc1` with one wheel and one sdist.
- The latest main CI run checked at task start succeeded for the starting SHA.
- No classic main-branch protection or repository ruleset was returned by
  GitHub. The `testpypi` and `pypi` Environments do have protection rules;
  `pypi` requires a reviewer. No approval or protection will be bypassed.
- The official pinned EmbeddingGemma 2 model card confirms MRL dimensions
  768/512/256/128, leading-dimension truncation, and L2 re-normalization.
- The pinned Transformers 5.20.1 configuration makes vision/audio configs
  optional, and its model constructor creates those towers only when their
  configs are present. The implementation uses `AutoConfig` overrides, not
  post-load layer removal. Text-only and image-plus-text loading both passed
  real-model CPU checks.
- The default model loading configuration remains unchanged. Explicit
  `modalities=("text",)` and `("text", "image")` may omit unused towers.
- Local Python is 3.12.10 with PyTorch 2.14.1+cpu and Transformers 5.20.1.
  CUDA is unavailable in this environment. The project virtual environment
  exists. `uv` 0.13.3 is available as `python -m uv`.
