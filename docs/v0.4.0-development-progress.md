  `pypi` requires a reviewer. No approval or protection will be bypassed.

  768/512/256/128, leading-dimension truncation, and L2 re-normalization.

  optional, and its model constructor creates those towers only when their
  configs are present. The implementation uses `AutoConfig` overrides, not
  post-load layer removal. Text-only and image-plus-text loading both passed
  real-model CPU checks.
- The default model loading configuration remains unchanged. Explicit
  `modalities=("text",)` and `("text", "image")` may omit unused towers.
- The default project environment uses Python 3.12.10, PyTorch 2.14.1+cpu,
  and Transformers 5.20.1. `.venv-cuda` uses PyTorch 2.14.1+cu130; CUDA is
  available on an NVIDIA RTX 4070 Ti SUPER and BF16 is supported. `uv` 0.13.1
  is available as `python -m uv`.
