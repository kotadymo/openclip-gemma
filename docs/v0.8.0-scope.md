# OpenVLCLIP v0.8.0 — agreed scope

**Decision date:** 2026-10-23  
**Status:** Development only; no v0.8.0 release has been published.

## Goals

| Workstream | Target | Status |
| --- | --- | --- |
| SigLIP 2 FixRes expansion | `siglip2-base-384` (768D), `siglip2-large-256` (1024D), `siglip2-so400m-384` (1152D) | Merged in [PR #53](https://github.com/kotadymo/openvlclip/pull/53); official real-weight numerical parity not yet measured |
| Meta PE-Core | T16-384 and S16-384, exposed via shared image/text API | Planned, not implemented |
| Search performance | Preserve exact search and index format; reduce Python candidate sorting with NumPy partition; FAISS remains optional pending measurements | Implemented in development PR; end-to-end performance not yet benchmarked |
| DINOv3 + dino.txt | **Explicitly excluded from v0.8.0** | Deferred; no checkpoint downloads, backend work, Registry entry, release tests, or DINOv3 license/access requirements |
 
If both PE-Core variants are validated and registered, the intended release Registry size is **10 checkpoints**: 5 from v0.7.1 + 3 SigLIP 2 additions + 2 PE-Core variants. The search-speed improvement adds no model checkpoints.

## Compatibility and minimum release checks

- Maintain the existing five v0.7.1 model APIs and index/EmbeddingSpace compatibility.
- Preserve the three added SigLIP 2 models' independently pinned source revisions, 384/256/384 image sizes and 768/1024/1152 dimensions; do not claim verified numerical parity until an independent official-checkpoint comparison has actually run.
- PE-Core checkpoints require separate identity/revision, processing parity and image/text/logit checks against official implementation before stable publication.
- Keep NumPy exact search as the default and preserve score/ranking semantics and existing index storage. Make FAISS or any ANN option strictly optional, with latency/memory and (for ANN) recall comparisons before claiming benefit.
- Reuse normal fast CI and existing Trusted Publishing; avoid creating heavyweight matrix/model-loading jobs or making external benchmark suites mandatory.
- Do not change `pyproject.toml` version to 0.8.0 or create a release tag until the actual scope has been implemented and required checks passed.
- **No DINOv3-related approval, license acceptance, gated weight download, or model parity is part of v0.8.0 completion.** Preserve [the separate DINOv3 research notes](v0.8.0-dinov3-dinotxt-prerequisites.md) only as future background.

## Implementation sequence

1. Verify current SigLIP 2 variants with pinned official weights, recording numeric parity and memory constraints.
2. Add PE-Core T16-384 and S16-384 as an optional common backend with pinned checkpoint revisions.
3. Benchmark and implement modest search acceleration without regressions; defer FAISS/ANN if performance or packaging benefits cannot be shown.
4. Finalize v0.8.0 docs, targeted tests, package version and publish via the existing secured workflow.
