These revisions come from the Hugging Face model commit history. Pinning prevents silent model/processor drift. All three checkpoints have `model_type=siglip` and are loaded through the fixed-resolution `AutoModel` and `AutoProcessor` path without remote code. SigLIP 2 Large and SO400M use their own projection dimensions; the old constant 768 must not be applied to them. The `siglip2-base` (224) and `siglip2-naflex-base` entries remain unchanged.

## Required before v0.8.0 stable release

1. On a machine with available model weights, independently load each pinned checkpoint with official `transformers.AutoModel`/`AutoProcessor` and compare image features, text features, and official scale/bias logits against OpenVLCLIP using the **same** deterministic inputs. Document max absolute error, dtype, library versions, CPU or GPU, and actual available memory. Do not label fake-model tests as official parity.
2. Confirm the pinned processors produce exactly the configured FixRes sizes and their actual resize/normalization settings. Update `preprocessing_id` if actual official preprocessing differs.
3. Run one image-index build/search for each model, and confirm that indexes from another checkpoint are rejected even when native dimensions match.
4. Check the exact licensing at each pinned revision, and do not ship model weights in wheel/sdist.
5. SO400M's model.safetensors is approximately 4.54 GB; downloading and FP32 inference require ample RAM/VRAM. Do not make all-checkpoint heavyweight parity a normal CI gate.

Model sources: https://huggingface.co/google/siglip2-base-patch16-384 ; https://huggingface.co/google/siglip2-large-patch16-256 ; https://huggingface.co/google/siglip2-so400m-patch14-384 .
